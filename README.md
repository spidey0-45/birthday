# 🎂 Cute Birthday Website ✨

A beautifully designed and interactive **Birthday Celebration Website** created to make someone's special day even more memorable. This project features elegant animations, a warm color palette, smooth transitions, and a responsive layout to deliver a delightful user experience.

---

## 🌟 Features

- 🎉 Beautiful birthday-themed landing page
- 💖 Cute and elegant UI design
- 🖼️ Interactive photo gallery
- ✨ Smooth animations and transitions
- 📱 Fully responsive for mobile, tablet, and desktop
- 🎨 Modern fonts and aesthetic color palette
- 💝 Personalized birthday message
- ⚡ Fast and lightweight

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
